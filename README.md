# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop web application built with React and Redux Toolkit. It allows users to explore a diverse collection of houseplants, learn about their unique benefits, and manage a dynamic shopping cart.

## Features
- **Interactive Landing Page**: Modern welcoming interface with company overview and "Get Started" navigation.
- **Product Listing**: Plants categorized into Air Purifying, Aromatic Fragrant, Insect Repellent, Medicinal, and Low Maintenance, with thumbnails, descriptions, and pricing.
- **Dynamic Shopping Cart**: Real-time cart badge counter, quantity increment/decrement, item deletion, and subtotal/total price calculations powered by Redux Toolkit.
- **Responsive Design**: Built using clean CSS and responsive layouts for desktop and mobile devices.

## Technologies Used
- React (Vite)
- Redux Toolkit & React-Redux
- CSS3
